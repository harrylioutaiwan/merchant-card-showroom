# Merchant Card Showroom 設計筆記

## momo 卡片觀察

依使用者提供的 2026-11-27 截圖分析。

| 參考畫面 | 可見的商品資訊與版型 | Showroom 決策 |
| --- | --- | --- |
| 圖 2 首頁精選榜 | 圖片、排名、品名、促銷價與刪除線價格，部分商品附評價與銷量 | 保留價格層級及選填評價。排名屬於榜單位置 |
| 圖 3 限時搶購 | 活動價、原價、剩餘組數，倒數位於整個活動區 | 保留促銷標示。庫存與倒數需要即時資料，留待有資料來源時接入 |
| 圖 4–5 牙膏搜尋 | 同商品可呈現為方格或橫列，價格、優惠與配送資訊可沿用 | 以同一個商品模型與元件支援兩種排列 |
| 圖 1 首頁及圖 6–7 商品詳情 | 首頁活動入口與詳情的規格、配送和放大圖服務不同操作 | 本次以瀏覽和比較用的商品卡為交付範圍 |

活動頁另可見「起」與領券文案。起價為展示價的型別，領券是促銷提示。結帳價格屬於獨立業務規則。[momo 年末熱銷榜](https://www.momoshop.com.tw/edm/cmmedm.jsp?lpn=O7EvvOwNDYf)

## 實作策略

先完成卡片渲染，再串接總覽、單卡編輯與儲存，最後從獨立 HTML 驗證重用。
三筆假資料覆蓋固定促銷價、起價與領券提示。卡片元件僅接收資料與展示設定，
由 Showroom 負責導覽與持久化。原生 HTML 範例能直接使用同一個元件。
