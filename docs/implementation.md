## 驗收

- `npm test` 驗證有效與無效設定、原型儲存資料相容、儲存錯誤、商品及版型隔離、重設與 preset 解析。
- `npm run build` 驗證 TypeScript 與兩個靜態入口的正式建置。兩個入口均在瀏覽器渲染。Vite 只略過 Material UI 套件的 `use client` 靜態打包提示。
- 瀏覽器驗收涵蓋四種呈現、單卡顯示設定、搜尋兩版型各自的顯示偏好、重整、重設、損壞與拒絕儲存、獨立 HTML，640 px 預覽在各視窗寬度下的邊界與標題列與側欄捲動時的固定位置，以及選項超出側欄高度時的獨立捲動。

- 側欄驗收涵蓋鍵盤展開與收合，四種卡片型態在「所有卡片」下的階層，以及單卡從內部導覽或外部連結進入時的返回行為。
- 媒體驗收涵蓋滑鼠、觸控、鍵盤、圓點、兩個顯示開關的保存、焦點回復及關閉後卸載播放器。以受控的播放器回應重現站外播放受限時的外部觀看入口。另以 Chrome 向 YouTube 載入示例影片並驗證播放時間有前進。
