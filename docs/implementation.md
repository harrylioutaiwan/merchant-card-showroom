課題原始建議使用第一筆到最後一筆 commit，或第一筆後約 120 分鐘內的提交，作為實作時間參考。本提交保留完整原型歷史。於正式 Phase 1 架構審查前已建立的原型提交是 `06a8f56` 與 `9ae2c8e`。審查完成後，使用者確認可開始正式 React 實作並指定採用 momo 色系。Git 時間戳記保留原始順序，包含前期原型與討論間隔。

## 驗收

- `npm test` 驗證有效與無效設定、原型儲存資料相容、儲存錯誤、商品隔離、重設與 preset 解析。
- `npm run build` 驗證 TypeScript 與兩個靜態入口的正式建置。
- 瀏覽器驗收涵蓋四種呈現、單卡編輯、搜尋兩版型共用狀態、重整、重設、損壞與拒絕儲存、獨立 HTML 和窄螢幕。
